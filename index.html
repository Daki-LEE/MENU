APK 받기

아직 플레이 스토어에 없어서 설치 파일로 받아요. 누르면 바로 다운로드돼요.

  1. 받은 파일 열기 알림창에서 GWHS_MENU….apk 누르기. 알림이 없으면 내 파일 → 다운로드에 있어요.
  2. 출처를 알 수 없는 앱 허용 처음 한 번만 물어봐요. 설정 눌러서 이 출처 허용 켜고 뒤로 가기.
  3. 설치 Play 프로텍트 창이 뜨면 무시하고 설치. 스토어에 안 올라간 앱이라 뜨는 거예요.
  4. 위젯 추가 홈 화면 빈 곳 길게 누르기 → 위젯 → 강원학사 식단 → 관악이나 도봉 중에 내 학사 고르기.

위젯 오른쪽 위 ↻ 누르면 새로고침, 위젯을 누르면 일주일 식단이 열려요. 새 버전은 똑같이 받아서 설치하면 덮어써져요.
