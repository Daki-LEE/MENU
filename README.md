# 강원학사 식단 위젯

관악학사·도봉학사 식단을 홈 화면 위젯으로 보여주는 안드로이드 앱이에요.

**[APK 받기](https://raw.githubusercontent.com/Daki-LEE/MENU/main/GWHS_MENU.apk)** · 현재 버전 v1.0.2

## 설치
1. 위 링크로 APK 받기
2. 받은 파일 열기 → "출처를 알 수 없는 앱" 허용
3. Play 프로텍트 창이 뜨면 "무시하고 설치"
4. 홈 화면 길게 누르기 → 위젯 → 강원학사 식단 → 관악 또는 도봉

새 버전도 같은 링크로 받아서 설치하면 덮어써져요.

강원인재원 홈페이지 주간식단을 가져와서 보여줘요. 학사에서 만든 공식 앱은 아니에요.
